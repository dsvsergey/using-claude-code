# Claude Code для команди

Статичний сайт-гайд: налаштування, локальна база знань, економія токенів, Spec Kit, кращі практики.

## Запуск локально

```bash
python3 -m http.server 8000   # відкрити http://localhost:8000
```

або просто відкрити `index.html` у браузері.

## Публікація

Будь-який статичний хостинг: GitHub Pages (Settings → Pages → branch `main`, `/`), Netlify, Cloudflare Pages, внутрішній nginx.

## Як оновлювати

Весь контент — в `index.html` (українська) та `index.ru.html` (російська), по одній `<section class="card">` на розділ. Новий розділ = нова секція + посилання в `<nav id="toc">` **в обох файлах** з однаковим `id` (на нього спирається перемикач мови). Зміни — через PR.

## Мови

- Перемикач UK/RU у верхній панелі зберігає вибір у `localStorage` і поточний розділ (`#якір`).
- `lang.js` (у `<head>`) перенаправляє на збережену мову ще до рендеру.
- Рядки інтерфейсу з JS (кнопка «Копіювати») — в обʼєкті `i18n` у `script.js`.
- Чекліст онбордингу має однакову кількість пунктів в обох мовах — його стан спільний.
